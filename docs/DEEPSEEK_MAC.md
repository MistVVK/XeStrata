# DeepSeek V4.1-Flash

Strata no longer runs DeepSeek V4.1-Flash. Version 0.2.13 was the last one that set it up and started it on a Mac.
Model files you already downloaded stay where they are. When you try to start one, Strata names the folder and its size, so you can delete it if you no longer need it.
To run a model now, run `strata launch` (or open the app) and choose one of the Qwen models: [MODELS.md](MODELS.md) lists them.
