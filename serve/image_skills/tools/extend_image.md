# extend_image

When: the user wants more of the picture around it: wider, taller, another shape, more of the scene.

- `aspect` for a shape the user names (`16:9` for a wallpaper, `9:16` for a phone); pixels for "a little more on the
  left" and the like.
- The prompt says what the whole image shows, the new area included; nothing about extending.
- To change what is in the picture, edit_image; to make it larger with the same content, not this.
