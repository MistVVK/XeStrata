# Image prompts

- Write the prompt briefly, from what the user asked for.
- Add nothing the user did not ask for: no subjects, setting, style, light, quality tags or details of your own,
  unless the chosen model's rules below ask for them.
- Drop nothing the user asked for.
- Put the words the image shows in double quotes, exactly as given.
- Follow the chosen model's own rules, when it has them.
