libatomic.so.1: the GNU atomic library, part of the GCC runtime

This engine package carries an unmodified copy of libatomic.so.1 from the build machine. The AMD ROCm library
librocm_sysdeps_numa.so.1 in this package needs it, and some Linux systems (containers, minimal installs) do not have it.
