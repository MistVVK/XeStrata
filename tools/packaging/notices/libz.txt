libz.so.1: the zlib compression library

This engine package carries an unmodified copy of libz.so.1 from the build machine. The oneAPI Unified Runtime loader
libur_loader.so.0 in this package needs it, and some Linux systems (containers, minimal installs) do not have it.
The 0.2.16 Intel Arc (SYCL) package bundles zlib 1.3 from Ubuntu 24.04 (distribution package zlib1g 1:1.3.dfsg-3.1ubuntu2.3).
